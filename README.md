# [nocp.space](https://nocp.space)

This is Norcleeh's Site written in Next.js (vinext) + TypeScript. Deployed on Cloudflare Workers.

## Setup

```bash
git clone https://github.com/nocpiun/nocp.space.git
cd nocp.space
npm ci
```

## Development

```bash
npm run dev
```

## Build and preview

```bash
npm run build
npm run start
```
