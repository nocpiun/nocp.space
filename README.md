# [nocp.space](https://nocp.space)

This is Norcleeh's Site written in Next.js (vinext) + TypeScript. Deployed on Cloudflare Workers.

Also available in CLI, try `npx nocp.space`

## Setup

```bash
git clone https://github.com/nocpiun/nocp.space.git
cd nocp.space
npm ci
```

## Development

- **Site:**

```bash
npm run dev
```

- **CLI:**

```bash
npm run dev
npm run dev:cli
```

## Build and preview

```bash
npm run build
npm run start
```

## CLI

```bash
npm run build:cli
npm run cli
```
